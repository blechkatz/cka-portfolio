# CKA Lab & Kubernetes Showcase

Willkommen in meinem praktischen Kubernetes-Lab. Hier dokumentiere ich meine Vorbereitung auf die **Certified Kubernetes Administrator (CKA) Prüfung

## Mein Setup
- **Betriebssystem:** Ubuntu Linux (VM)
- **Cluster:** Local K8 mit kind
- **Tools:** 'kubectl' Bash Aliases, Linux-CLI

## Inhalt
- '/manifests' - Meine Praxis-Beispiele für Pods, Services, Deployments und mehr. 
- '/troubleshooting' - Gefundene Fehler- Log-Analysen und deren Lösungen.
